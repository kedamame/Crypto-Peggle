## 一行コンセプト

> **「静かな点描の盤面を撃ち抜いて、宇宙の底まで潜るペグシューター」**
> — 表向きは何も語らない。深く潜った者だけが、盤面に紛れ込む「異物」に気づく。

DotShot は二重構造のゲームである。**表の顔**は、クリーム地にインクの点描だけで描かれたミニマルなペグゲーム（「Clear all the orange pegs.」）。**裏の顔**は、レベル＝深度が進むほど未知で異様な宇宙現象が盤面に侵入してくる深宇宙潜行。この二重性そのものがコンセプトであり、**裏の顔を運営側から明かさないこと**が最も重要な規律である。

## 1. 4つの柱（確定コンセプト）

### 柱1: 無言のミニマリズム
クリーム地 `#ede9df`・黒インクの点描・4色パレット（[CLAUDE.md](../CLAUDE.md) §2 のデザイン契約）。
UI テキストも manifest の説明文も、宇宙を語らない。世界観はテキストではなく**盤面に現れる異物のビジュアルでのみ**語られる。

- 深度進行のインジケータ（depth dots）にすら名前とツールチップを付けない、という既存実装の判断はこの柱の実践である。
- 対外文言（説明文・タグ・シェア文言）に「cosmos」「space」「宇宙」等の語を**入れない**。

### 柱2: 深度＝異様さ
レベルは単なる難易度ではなく**深度**である。浅層は身近な障害物、深く潜るほど未知で強力で予測困難な宇宙現象が増える（lv7 ブラックホール → … → lv99「無」）。

- 新ギミックは狙い線プレビューに反映されない（[CLAUDE.md](../CLAUDE.md) §7.5）。**「読めない宇宙」がそのまま難しさ**であり、これはフェアネスの欠如ではなく設計である。
- 詰みは作らない（クリア条件に干渉しない、[CLAUDE.md](../CLAUDE.md) §4）。宇宙は理不尽だが、潜行を恒久に止めることはない。

### 柱3: 1ラン＝1潜行
毎回 lv1 から始まる。進行保存はない。残弾が尽きたらその潜行は終わり、到達深度がそのランの成果である。

- **深部が遠いことは欠陥ではなく価値**。lv90 台の光景は、そこまで一息に潜り切った者だけへの報酬である。
- 進行保存・チェックポイント・「到達済み深度からの再開」は**採用しない**（将来検討する場合も §4 北極星の制約に従う）。

### 柱4: 発見の非対称性
深部を見た者はごく少数に保たれる。「lvXX で変なものを見た」というプレイヤー同士の証言・スクリーンショット・キャストが**コミュニティにおける通貨**になる。

- 運営は深部の内容を公式には一切説明しない（攻略情報・ギミック一覧を対外公開しない）。
- 発見の伝播はプレイヤーの口コミとシェアに 100% 委ねる。

## 2. 競争軸

- **主軸は到達レベル（深度）**。「どこまで深く潜れたか」がプレイヤーの誇る数字。スコアは副次的な数字として残す。
- lv99「無」が現在の底（宇宙ギミック・カタログ #47 完走時点）。ただし**底は動きうる**——99 以降へのギミック追加は将来の検討対象であり、「底に到達した」ことを恒久の称号として保証しない。

---

## 3. Base の位置づけ（現在形＝層1: 記録の再解釈）

Base（オンチェーン）は単なる配信インフラではなく、**世界観の一部**として意味づける。現時点で確定するのは「層1: 記録の再解釈」——既存実装を変えず、意味づけのみを定める。

| 既存機能 | コンセプト上の意味 |
|---|---|
| スコア/レベルのオンチェーン記録 | **潜行の痕跡が宇宙（チェーン）に恒久に刻まれる**。消えない、改竄されない、誰のものかが証明される |
| $0.001 USDC のコンティニュー（+3発）/ 追加弾（+1発） | **深淵で燃やす燃料**。潜行を続けるための微小な実燃料であり、勝利を買う手段ではない |

- 実装は既存のまま（x402 マイクロペイメント、submitScore）。変えるのは言葉と設計判断の基準だけ。
- この意味づけにより、将来リーダーボードを表示する場合は「ランキング表」ではなく**「潜行者たちの痕跡の碑」**としてデザインする。

## 4. 北極星（将来の検討項目、採用未定）

以下は**現在のコンセプトには含まれない**が、進化の方向として共有しておく候補。採用時は必ず柱1〜4と衝突しないことを確認する。

- **層2: チェーンが盤面に写る** — ブロックハッシュやウォレット履歴が宇宙の生成に影響する。実装時はレベル生成の決定論（[CLAUDE.md](../CLAUDE.md) §7.6）との整合設計が必要。
- **層3: 他の潜行者の痕跡** — 他プレイヤーのオンチェーン記録が、自分の盤面に「残骸」「ゴースト」として漂着する。宇宙が共有空間になる。
- **層4: 集団で一つの宇宙** — 全プレイヤーの行動が単一のオンチェーン宇宙状態を進化させる。最も実験的・高コストな遠い北極星。
- **シェアOGの異変** — 深部到達者のシェア画像にのみ、到達深度に応じた異物が写り込む。運営は何も語らず、**プレイヤーのシェアだけが囁きになる**。「隠す」方針（柱1・柱4）と両立する数少ない新規獲得フックであり、北極星の中では優先度が高い。
- **ラン構造の緩和** — 現時点で採用しない。検討する場合も「1ラン＝1潜行」（柱3）と衝突しない形（例: 記録・証明の側を豊かにする方向）に限る。深度への直接ショートカットは柱3と§5に反するため不可。

## 5. アンチゴール（DotShot がやらないこと）

1. **宇宙を説明文・UI テキストで語らない** — 「隠された発見」を運営自身が壊さない。マーケティング文言でのネタバレも不可。
2. **背景を宇宙 skybox にしない** — 星空・星雲は描かない。紙（背景）の色は深度とともに薄い黒紫へ沈む（2026-07-12 改定、[CLAUDE.md](../CLAUDE.md) §1）が、あくまで「紙とインク」の世界のまま紙が沈むだけであり、宇宙空間の描写にはしない。宇宙感の主体はハザードのビジュアル。
3. **狙い線プレビューにハザードを反映しない** — `computeTrajectory` は不可侵（[CLAUDE.md](../CLAUDE.md) §7.5）。
4. **課金を pay-to-win 化しない** — 課金はコンティニュー/追加弾（＝燃料）の範囲に留める。**深度への直接ショートカット（レベルスキップ・深部スタート権）の販売はしない**。到達深度の重みは金で買えないからこそ競争軸として成立する。
