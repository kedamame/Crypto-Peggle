## 1. 視認性の階層（Tier 原則）

CONCEPT.md 柱2「読めない宇宙」との線引きは次の一文に集約される:

> **効果は読めなくていい。ただし、接触・消滅・テレポートする物体の存在は必ず見えること。**

「軌道がどう曲がるかわからない」は設計（フェアな難しさ）。「そこに物体があること自体が見えない」まま玉が消える/跳ねる/飛ぶのは理不尽（バグ級）。ハザードは効果の種類で4つの Tier に分類し、要求される視認性が異なる。

| Tier | 効果の種類 | 視認性要求 |
|---|---|---|
| **1** | 接触・消滅・反射・テレポート（実体/発火を持つ） | **明確に可視**。§2 の禁止色帯を主体色にしない。予告/発火フィードバック必須 |
| **2** | 強い連続フォース（引力・斥力・加速） | 可視。天体としての存在が読めること |
| **3** | 弱い場・環境系（視界・微修飾・演出） | 淡くてよい。静けさ自体が演出になりうる |
| **4** | 意図的不可視（不可視が本体） | 不可視を維持。ただし**周期的な tell（シマー・リビール等）必須** |

### Tier 4 保護リスト（改修対象外）

「見えないこと」がギミックの本体。視認性の低さは欠陥ではないため、**ビジュアル改修の対象にしない**。

- **#27 ダークフロー**（lv58）— 縁ストリーマがペグ同色なのも「気づかない力」の演出
- **#35 原始ブラックホール群**（lv76）— tell: 約140f周期のマイクロリング・トゥインクル
- **#37 CMBゆらぎシート**（lv74）— tell: 全域の極淡まだら＋超遅明滅
- **#6 ダークマター・ハロー**（lv48）— tell: 周期リビール（alpha最大0.82）
- **#47 無**（lv99）— 描かないことで描く。装飾追加は永久に禁止
- **#29 弾丸クラスターのDM塊** — 無描画＋60f毎シマー（可視化しない。玉側フィードバックで補償）
- 準保護: **#30 BAO** の砂色低コントラスト（「聞こえない音」の意図）、**#12 宇宙ボイド**の静けさ、
  **#32 GWハム**の「専用天体なし」方針（マーカー形状の調整のみ可）

## 2. 禁止色帯

背景（紙）クリーム `#ede9df`（全レベル不変・2026-07-13 再確定）・通常ペグ黒 `#0f0f0d` との識別を守るための帯域規則。

1. **クリーム近傍帯（`#e0d8c0`〜`#ffffff` のオフホワイト系）を Tier 1/2 の主体色にしない。**
   白はアクセント（コア閃光・衝撃波・ハイライト）にのみ使う。1〜2px の白ドットはクリーム地でほぼ消える。
2. **ペグ黒 `#0f0f0d` をハザード本体色にしない。**
   意図的な白黒反転デザイン（例: #15 反物質フレック）は白縁取り等で「ペグではない」と即時識別できる差別化が必須。
3. **同レベル帯に同系色ハザードを並べない**（既存の排他ルール: 重力波系リング族、赤系×赤彗星 等を踏襲）。

## 2.1 背景 vs ハザード記号分離（VisSep）

クリーム紙 `#ede9df` 上で「紙のシミ」と「盤面に紛れ込んだ異物」を取り違えないための文法。

> **効果は読めなくてよい。ただし「そこにハザードがある」ことだけは、背景塵と別の記号で常に読めること。**

| 層 | 記号 | 禁止 |
|---|---|---|
| **塵 `bgDots`** | 無彩色インク `#0f0f0d` のみ。ドリフト／マリンスノー。深部は α をさらに絞りハザード点群を勝たせる | 彩度付き塵・虹色化・紙の塗り替え |
| **Paper Mood** | 低α・無彩色寄りの粒／モアレ。紙の癖だけ | 血赤／紫／シアン等のハザード色族で新現象を擬似追加 |
| **ハザード（Tier1/2・接触型）** | **構造記号**必須（欠け環・2px弧・焦点・帯の点線）。主tell α床 **≥0.28〜0.34**。「散らばった1pxだけ」禁止 | クリーム近傍を主体色にする（§2） |
| **玉FX（第2チャンネル）** | 作用中は必ず色付き `pulseForceFx` / `pulseTwistFx` / `pulseFieldFx` | 背景が玉に色付き Force/Twist を付けること |

- **動き**: 流れる薄いインク＝背景／歳差・シマー・掃引・予告＝ハザード、と学習させる。
- **Tier4・準保護**（§1）は常時可視化しない。BAO等は弧点灯＋玉FXで補償する既存方針を維持。
