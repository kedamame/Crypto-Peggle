## 1. 共通実装レシピ

### 1.1 物理分類と対応テンプレ

| 分類 | 挙動 | コピー元 | サブステップ | effMinSpeed |
|---|---|---|---|---|
| 連続フォース型 | 範囲内で毎フレーム `vx/vy` に加算 | レンズ or パルサー | 不要 | 不要（加速のみなら） |
| パルス型 | 周期タイマー→短時間だけ強い力 | 重力波（波面）+ CME（予告演出） | 不要 | 不要 |
| 接触衝突型 | 重なった瞬間に反射/消滅/シフト | 彗星（円）or バンパー/ワームホール（OBB） | **必須** | 反射後に**必須** |
| 場の修飾型 | 範囲内で重力・速度スケールを変える | 真空バブル + freeze/mud の minSpeed 抑制 | 不要 | **抑制側の配慮が必須**（§1.4） |

### 1.2 決定論ルール（§7.6）

- 出現判定・座標・向きなど**レベル生成時**の乱数は、専用ストリーム
  `const xxxRng = makeRng((rng() * 0x100000000) >>> 0);` を **`generateLevel` 内の既存の全乱数消費の後ろ**
  （現在は `vacRng` ブロックの直後）に追加して使う。既存レベルの配置を1ビットも変えないため。
- **実行時**の毎フレーム挙動（パルスの向き再抽選・ドリフト等）は `Math.random()` でよい。

### 1.3 禁止事項

- `computeTrajectory` への反映は**いかなる場合も禁止**（§7.5。狙い線に映らない＝フェアな難しさ）。
- 背景クリーム地 `#ede9df` を塗り替えない。宇宙感はハザード自身の彩度ドットで出す。
- クリア条件（orange 全消し／ボス撃破）に干渉しない。ペグを消す・増やすギミックは作らない。
- 描画ブロックの末尾で必ず `ctx.globalAlpha = 1` に戻す。

### 1.4 詰み回避の設計指針（§4-4）

- 玉を減速・停留させる案は、**freeze/mud と同じ per-ball タイマー方式**で `dynMinSpeed` を抑制しつつ、
  効果に時間上限を付ける（stuck-rescue 220f が最終保険だが、頼り切らない）。
- 玉を閉じ込めうる案（上向き力・停留場）は、**周期的な解放**（ポップ/フェーズ消滅/移動）を必ず設計に含める
  （真空バブルの「rMax でポップ」が実例）。
- 力は距離減衰 `t = 1 - dist/range; f = BASE * t * t` に統一し、速度は必要に応じ `BALL_SPEED * 2` でクランプ。

### 1.5 配色の原則

既存ハザード色（重複を避ける）: BH=血赤 / ワームホール・レンズ・霧=紫 / 青彗星=空色 / 赤彗星=赤 /
CME=橙 / パルサー=シアン白 / 重力波=銀灰 / 真空バブル=緑。
各案のビジュアル欄に指定色を記載済み。ハザードは「クリーム地に紛れ込んだ自己発光の異物」に見えること。

### 1.6 共通アニメーション言語（各案の「アニメーション」欄はこの語彙で指示される）

動きの発明は禁止。すべての動きは、実コード（`src/components/CryptoPeggleGame.tsx`）に既にある
次の10イディオムの組み合わせで作ること。**動きは全てドットの明滅・移動・回転で表現する**
（形状変形やスケーリングは「点描の再配置」として行う）。

| イディオム | 数式/手法 | 実例（コード内） |
|---|---|---|
| **パルス明滅** | `a = base + Math.abs(Math.sin(frame*k))*amp`。k=0.004〜0.06=鈍い/不気味、0.1〜0.15=通常、0.2〜0.33=危険/高速 | bombペグ k=0.14、パルサー k=0.22、シールド k=0.11 |
| **回転ドットリング** | `angle = (i/n)*2π ± frame*k`。k=0.008〜0.035 | レンズ、ボス内輪、パルサーのハロー |
| **リング衝撃波** | 半径 `r0 + t*Δr`・alpha `(1-t)*a0` を10〜36fで展開 | ボス rearmFlash（18f）、彗星 hitFlash（26f） |
| **点滅予告（テレグラフ）** | 発動30〜45f前から明滅、強度は `wt = 1 - timer/WARN` でランプ | 彗星の端シェブロン、CMEの警告バー（40f） |
| **ドット流（フロー）** | 位置を `(base + frame*spd) % length` でスクロール | 霧の雲（spd 0.18〜0.56）、彗星の尾 |
| **ヒットフラッシュ** | `hitFlash` カウントダウン中は白/明色に差し替え | ボス（10f）、バンパー（20f） |
| **バースト** | `spawnBurst(g, x, y, vx, vy, color)` を1発 | 全ハザード共通の接触演出 |
| **微ジッター** | 事前計算 cosP/sinP 方式（`Dot` interface / `drawDots`） | 全ドット雲。**per-frame の生 trig 大量呼びは禁止** |
| **フェード生滅** | alpha を約20fでランプ（`WORMHOLE_FADE = 20` が基準。10〜36fの範囲内） | ワームホールの出現/消失 |
| **呼吸** | 半径やサイズを `1 + sin(frame*k)*0.03〜0.06` で揺らす | 泥ペグの wobble（k=0.06） |

**テンポの世界観ルール**:
- 不気味なもの・古いもの・巨大なものほど**遅く**（k ≤ 0.06）、危険なもの・小さいものほど**速く**（k ≥ 0.2）。
- 深度ゾーンが深いほど動きは「静かで異様」に（各ゾーンバナーのトーン指針に従う）。
- 予告→発動を持つものは必ずテレグラフを入れる（プレビュー無反映の代償として、動きで読ませる）。

**禁止事項**: クリーム地の塗り替え / radial-gradient・box-shadow 的表現の多用 /
`globalCompositeOperation` の使用 /
1フレームあたり数百回超の生 `Math.sin/cos` 呼び（事前計算かメモ化 `circleTrig` を使う）/
描画ブロック末尾の `ctx.globalAlpha = 1` 戻し忘れ。

### 2.1 ホワイトホール — White Hole（Lv目安 23）
- **元ネタ**: ブラックホールの時間反転解。何も入れず、すべてを吐き出すだけの仮説上の天体。
- **出現**: 50%ロール。スケーリング: 斥力 `0.55 + min(0.55, (lv-23)*0.03)`。
- **分類**: 連続フォース型（**BH引力ブロックのコピー・符号反転・吸収判定を削除**）。
- **物理**: 範囲 `R=140`。`t=1-dist/R; f=WH_PUSH*t*t; ball.v += (d̂_中心→玉) * f`（外向き）。
- **詰み回避**: 斥力のみ＝玉を留める力が存在しない。
- **ビジュアル**: BHの渦の白黒反転。純白〜青白（`#ffffff`/`#e8f0ff`）の**逆回転**する噴出渦ドット＋
  白コア（`drawSolidCircle`）。プレイヤーが「BHの逆だ」と直感できる形にする。
- **アニメーション**: 常時=噴出渦を回転ドットリング（k=0.02、**BHと逆回転**）＋中心→外への
  ドット流（spd 0.8、外縁でフェード）。白コアのみパルス明滅（k=0.08）。
  接触=玉が押された瞬間、玉と中心を結ぶ線上に白1pxスパーク2個（3f）。生滅=なし（常設）。
- **実装メモ**: 最も簡単な1案。既知（BH）の反転なので「未知」導入の入口に最適。

### 2.2 マグネター — Magnetar（Lv目安 31）
- **元ネタ**: 宇宙最強の磁場を持つ中性子星。星震で巨大フレアを放つ。
- **出現**: 50%ロール。パルス周期 `max(180, 300-(lv-31)*8)` フレーム。
- **分類**: パルス型（重力波の周期タイマー＋CMEの予告演出を合成）。
- **物理**: 帯電40f（予告）→ 放出6f: 範囲 `R=170` 内の全玉に
  `f=1.6*t*t` の外向きインパルス/フレーム。放出後は無害。
- **詰み回避**: 瞬発の斥力のみ。
- **ビジュアル**: 鉄灰の星体（小さい `drawSolidCircle`）＋黄白（`#ffe66a`/`#fff8d0`）の磁力線アーチが
  帯電中に明滅→放出時に全方位スパーク（`spawnBurst` 黄白）。
- **アニメーション**: 常時=星体を鈍いパルス明滅（k=0.05）＋磁力線アーチの回転ドットリング（k=0.01）。
  予兆=放出40f前から磁力線が速いパルス（k=0.25）へ移行し白熱（テレグラフ）。
  発動=リング衝撃波（6f、R=170まで、黄白）＋ `spawnBurst` 黄白。
  接触=力を受けた玉ごとに1px白スパーク3個。生滅=フェード20f。
- **実装メモ**: 予告→炸裂のリズムは CME の `WARN` パターンを流用。

### 2.3 ローグプラネット — Rogue Planet（Lv目安 32）
- **元ネタ**: 恒星を持たず銀河を漂う自由浮遊惑星。暗黒の中を静かに横切る。
- **出現**: 45%ロール。移動速度 `0.35 + (lv-32)*0.01`（ゆっくり）。
- **分類**: **移動する**連続フォース型＋接触衝突型（彗星の移動＋バウンス、BHの引力を合成）。
- **物理**: 半径 `r=22` の実体（法線反射・彗星の式を流用、**effMinSpeed クランプ必須**）＋
  周囲 `R=130` の引力 `f=0.35*t*t`。画面を横断し、端で反対側から再進入（または折り返し）。
- **詰み回避**: 惑星自体が移動し続けるため停留点が存在しない。吸収なし。
- **ビジュアル**: 濃藍鼠（`#20283a`）の点描惑星＋淡灰のリング（傾いた楕円ドット列）。
  発光しない「暗い異物」として描く（唯一の非発光ハザード＝はぐれ感）。
- **アニメーション**: 常時=移動そのものが主アニメ。自転は `drawDots` の rot 引数でごく遅く（k=0.004）、
  リングは呼吸（k=0.02、振幅0.04）。**発光の明滅は一切入れない**（暗い異物の演出）。
  接触（バウンス）= `spawnBurst` 灰藍＋ヒットフラッシュ8f。生滅=画面外へ出て反対側から再進入（フェード不要）。
- **実装メモ**: 引力＋実体の合成でスリングショット（加速旋回）が自然に発生する。

### 2.4 クエーサージェット — Quasar Jet（Lv目安 33）
- **元ネタ**: 超大質量ブラックホールが噴き上げる光速級のプラズマ柱。
- **出現**: 45%ロール。加速 `0.30 + (lv-33)*0.015`。
- **分類**: 連続フォース型（パルサーのビーム判定を**固定角・片方向**にした変形）。
- **物理**: 生成時に柱の位置 x・向き（上噴き/下噴き）・半幅 `HALF=16` を決定。柱内の玉に
  軸方向の加速を毎フレーム加算、`BALL_SPEED*2` でクランプ（風と同じ作法）。
- **詰み回避**: 一方向への加速のみ。上噴きの場合も柱の外に出れば通常重力（左右移動は自由）。
- **ビジュアル**: 菫色（`#8a5adc`）の柱状ドット流（流れ方向にドットがスクロール）＋

### 2.22 裸の特異点 — Naked Singularity（Lv目安 53）

  生滅=なし（常設）。
- **実装メモ**: 乱流の `sin(3θ + frame*k)` は決定的な式なので再現性がありデバッグ可能。
  「予測不能に見えるが実装は単純」が狙い。

### 2.42 超放射 — Superradiance / BH Bomb（Lv目安 85）
- **元ネタ**: 回転BHのエルゴ領域では、波がBHの回転エネルギーを**奪って増幅されて**出てくる。鏡で囲えば爆弾になる。

- **実装メモ**: エルゴ球（#7、力の帯のみ）との違い＝こちらは引力があり、加速する。同時採用時はLv帯を離す。

### 2.43 負質量ブロブ — Negative Mass Blob（Lv目安 87）
- **元ネタ**: もし負の質量が存在したら——正の質量は負を引き、負は正を押す。結果、**押しながら追いかける**
  暴走ペアが生じる。物理学で最も奇妙な思考実験の一つ。
- **出現**: 35%ロール。
- **分類**: 移動体＋連続フォース型（追跡する斥力源）。
- **物理**: ブロブ（力の中心、実体なし）は最寄りの玉へ `0.6px/f` で追尾移動。同時に R=100 内の玉を
  外向きに押す `f=0.45*t*t`。玉がいなければ静止。画面端で停止（出ない）。
- **詰み回避**: 斥力のみ＝玉は常に逃がされる。追尾は玉より遅い。速度クランプ推奨。
- **ビジュアル**: 「存在の欠落」＝白抜きの輪郭点線だけで描き、内部は背景よりわずかに明るい。
  影ではなく**穴**。追いかけてくる穴。
- **アニメーション**: 常時=白抜き輪郭点線の呼吸（k=0.03）。内部の「明るさ」は静止。
  追尾中=輪郭の進行方向側のドットを疎に、後方を密に再配置（穴が「伸びる」変形）。
  静止に戻るとき輪郭が3fで真円に復帰。接触=**無演出**（音もなく押される不気味さ）。生滅=なし。
- **実装メモ**: 追尾はフレームごとに `normalize(ball-blob)*0.6` を足すだけ。複数玉時は最寄り優先。

### 2.44 泡宇宙の衝突痕 — Bubble Universe Collision（Lv目安 91）

### 2.45 ビッグリップ前兆 — Big Rip Precursor（Lv目安 93）
- **元ネタ**: ダークエネルギーが強まり続ける（ファントム）なら、宇宙は銀河も原子も引き裂いて終わる。
  DESIの「ダークエネルギーは進化している」観測（2024-25）で再び現実味を帯びた終末シナリオ。
- **出現**: 40%ロール。
- **分類**: パルス型・盤面全域・**漸増**（レベル内で終末が近づく）。
- **物理**: 周期400fごとに膨張イベント20f: 全玉に盤面中心から `f = H_rip * dist`（遠いほど強い）。

- **詰み回避**: 斥力のみ。中心付近はほぼ無力。
- **ビジュアル**: イベント中、背景インク点の間隔が中心から比例して広がり、ゆっくり戻る

- **実装メモ**: #19 ダークエネルギー膨張域（局所・定常）との差別化＝全域・パルス・漸増。

### 2.46 共形サイクリック境界 — Conformal Cyclic Boundary（Lv目安 95）
- **元ネタ**: ペンローズCCC——宇宙の無限の未来と次の宇宙のビッグバンは、共形変換でつながった同じ面である。
  終わりは始まり。
- **出現**: 40%ロール。
- **分類**: 特殊（境界の再定義。**唯一、玉の経済に触れる案**——採否判断は下の注記を参照）。
- **物理**: 画面最下端に高さ20pxの境界帯（バケットのさらに下）。バケットに入らず落ちた玉が帯に
  達したとき、**その玉が未再誕なら**上端（発射台の左右ランダム）から速度の大きさを保存して
  再誕する（per-ball フラグで1玉1回）。2回目は通常どおり退場。
- **詰み回避**: 詰みとは逆方向（救済）。クリア条件には無関係。
- **ビジュアル**: 下端に極淡の虹色地平線（1pxの7色ドット列、alpha 0.2）。再誕時は上端に
  白い産声バースト＋新しい宇宙の最初の玉として一瞬金色に光る。
- **アニメーション**: 常時=虹色地平線ドット列の超遅い横送り（ドット流 spd 0.1、7色が順送り）。
  発動（再誕）=下端の接触点から白ドット1粒が上端まで縦に駆け上がる（6f）→上端で
  `spawnBurst` 白＋金の産声→再誕した玉が10f金の残光を纏う（バケットボールのブルームを短縮流用）。
  生滅=なし（常設）。
- **注記**: 玉1個あたり実質約1.5回のチャンスになるため、**深層の高難度を相殺するご褒美ギミック**
  として設計している。難度を下げたくない場合は不採用に。
- **実装メモ**: 玉の除去判定（`ball.y > H+40`）の直前に帯判定を挟む。

### 2.47 無 — The Nothing（Lv目安 99）
- **元ネタ**: 宇宙の外には何があるのか。空間も時間も法則もない「無」。この問いに物理学はまだ一文字も書けていない。
- **出現**: 35%ロール（最深部の到達点）。
- **分類**: 場の修飾型・**全ての力の不在**。
- **物理**: 円領域（R=110）。内部の玉には**重力を含む一切の力を適用しない**——完全な直線等速運動。
  minSpeed も stuck タイマーも領域内は凍結（直線なので詰まない）。壁・ペグ衝突だけは生かすが、
  生成時に領域内へペグ・他ハザードを配置しない。
- **詰み回避**: 直線運動は必ず領域を貫通して出る（力がないので留まれない）。
- **ビジュアル**: **何も描かない**。背景のインク点・微グレインさえ領域内では描画をスキップする。
  完全な空白の円。境界線すらない——インク点が円形に欠けていることだけが、そこに「無」がある証拠。
  玉が通過する間、玉の点描だけが空白に浮かぶ。
- **アニメーション**: **一切動かない**。内部は何も描かず、境界線もなく、bgDots が円形に欠けるだけ。
  接触・生滅の演出もゼロ。47案で唯一「アニメーションを持たないこと」自体が指示。
  実装者は装飾を足したくなっても**足さないこと**（何かを足した瞬間、それは「無」ではなくなる）。
- **実装メモ**: 力適用セクションの冒頭で `inNothing` を判定し、重力〜全ハザード力をガードする。
  #12 宇宙ボイド（低重力＋ドラッグ＝「薄い」）との差別化＝こちらは物理の**完全な不在**。
  カタログ全体の終着点として、最も静かで最も異様な一枚に仕上げること。

### 5.54 重力レンズ・コースティック — Gravitational Lensing Caustic（Lv目安 65）

- **元ネタ**: 重力レンズで背景天体が複数像に割れるとき、像が重なり合う**コースティック（折り畳み線）**上では
  輝度が鋭く集中する。JWST の六芒星もコースティックの一種。
- **出現**: 40%ロール。折り畳み線1本（二次ベジェまたは24点ポリライン、盤面幅の55%程度）。
  線の向き・曲率は `causticRng` で決定。
- **分類**: 接触線型・**サブステップ必須**。反射ではなく**法線成分の一方向増幅**（屈折の鋭い版）。
- **物理**: 線分の判定半幅 `CAUSTIC_HALFW = 5`。玉が線分に初めて進入（`WeakSet<Ball>` で1横断1発火）した瞬間:
  1. 線上の最近傍点を求め、接線 `t̂` と法線 `n̂`（折り畳みの明るい側へ向く向きは生成時に固定）に分解。
  2. `v_par = (v·t̂)t̂` は維持、`v_perp = (v·n̂)n̂` に `CAUSTIC_AMP = 1.35` を乗算（符号は明るい側へ）。
  3. 合成後 `effMinSpeed` クランプ必須。`BALL_SPEED*2` ハードクランプも適用。
  通常速度の玉にも作用するが、法線成分が小さい射角では効果は弱い＝読みにくさは維持。
- **詰み回避**: 接線は保存・増幅は1回きり・引力なし・吸収なし。横断後は通常重力のみ。
- **ビジュアル**: 折り畳み線に沿う金 `#d4b85a` の2pxドット列（疎ら、14〜18点）。
  横断時に線上の接触点だけ白 `#fff8e0` 2pxが6f点灯。境界の「折り畳み」はドット密度を中央で2倍に。
- **アニメーション**: 常時=金ドットのごく遅い明滅（k=0.008）＋折り畳み点（曲率最大）にだけ
  白ハイライト1粒が呼吸（k=0.05）。発火=接触点から折り畳み線方向へ金1pxスパーク3個（6f）。
  移動するハザードではない。
- **Tier**: 1（線に触れると方向が変わる）。折り畳み線全体を常時可視にすること。
- **実装メモ**: `closestOnPolyline`（ラニアケア流域で既存）を流用し最近傍セグメント＋法線を取得。
  #49 無衝突衝撃波の `ballSegmentProximity` パターンと `passingBalls: WeakSet<Ball>` をコピー。
  インターフェース例: `GravitationalCaustic { pts: {x,y}[]; brightSide: 1|-1; hitFlash; hitX; hitY }`。
  定数推奨: `CAUSTIC_HALFW=5`, `CAUSTIC_AMP=1.35`, `CAUSTIC_FLASH=6`, `CAUSTIC_DOTS=16`。
- **検証**: 16入射角で横断1回のみ・接線成分誤差&lt;1e-6・法線成分が明るい側へ増幅・
  同一玉の2回目ゼロ・600f以内離脱を孤立simで確認。

### 5.55 再電離前線 — Reionization Ionization Front（Lv目安 71）

- **元ネタ**: 宇宙再電離（z≈6〜10）。最初の銀河・クエーサーの紫外線が中性水素を電離させ、

- **物理**: 帯内（`|ball.y - reionY| < REION_BAND/2`）の玉に毎フレーム:

  帯外は無力。速度下限 `REION_MIN_SPD = BALL_SPEED * 0.40` を適用（freeze/mud 作法）。
  重力は帯内外とも通常どおり（減速のみで停留しない）。
- **詰み回避**: 帯は移動し続ける＝滞留不可。下向き微押しは重力と同方向で詰みを助長しない。
- **ビジュアル**: 前線の先端（進行側）に紫 `#7b5cff` の2pxドット列（全幅、8px間隔）。

  上端に紫の細い警告バー（alpha 0.5、テレグラフ）。
- **Tier**: 2（強い場だが帯は見える）。前線の位置が常に読めること。
- **実装メモ**: `GameState` に `reionActive: boolean`, `reionPeriod`, `reionTimer`, `reionY`（CME の

### 5.56 ニュートリノ振動 — Neutrino Flavor Oscillation（Lv目安 78）

- **元ネタ**: ニュートリノは飛行中に電子・ミューオン・タウの「味」が確率的に入れ替わる（振動）。
  質量そのものではなく**味状態の重ね合わせ**が時間発展する。
- **出現**: 40%ロール。楕円領域1個（`NEUT_RX=100`, `NEUT_RY=72`）、軸角は `neutrinoRng` で決定。
- **分類**: 連続フォース型・速度保存（量子泡の回転式を楕円ゲート内に限定）。
- **物理**: 楕円内の玉に毎フレーム、速度保存回転
  `Δθ = NEUT_AMP * sin(frame * NEUT_FREQ + ballIndex * NEUT_PHASE)` を適用。
  推奨: `NEUT_AMP=0.065`, `NEUT_FREQ=0.09`, `NEUT_PHASE=1.4`。
  楕円外は無力。平均回転はゼロ（sin 平均）だが、短期では味が「入れ替わった」ように曲がる。
- **詰み回避**: 速度保存のみ・引力なし・中心への引き込みなし。重力で必ず脱出。
- **ビジュアル**: 楕円内に3層の極淡ハロー（藍鼠 `#a8b8c8` / `#98a8b8` / `#8898a8`）を
  中心から ±8px / ±16px オフセットし、120°ずつ位相をずらして描く（3味の重ね合わせ）。
  境界線は描かない（Tier 3）。
- **アニメーション**: 常時=3ハローが互い違いに極低速呼吸（k=0.006、振幅4px）。
  玉が内部にいる間、8fごとに `fxTwist`（既存ヘルパー `pulseTwistFx`）を発火。
  白フラッシュは使わない。
- **Tier**: 3（弱い場）。3層ハローが「味の重ね合わせ」の tell として必須。
- **実装メモ**: 量子泡ブロック（`QF_ROT_AMP` 式）を楕円 `if` で囲むだけで足りる。
  Ball 新フィールド不要。`neutrinoOscillations: NeutrinoOscillation[]` 1要素でよい。
- **検証**: 500f速度diff≈0（浮動誤差内）、楕円外で回転ゼロ、16開始角で600f以内離脱を孤立sim。

### 5.57 重力波記憶 — Gravitational Wave Memory（Lv目安 85）

- **元ネタ**: 重力波が通過した後も時空に**永続的な歪み（メモリ効果）**が残ると予想されている
  （BMS対称性・ソフト定理）。一瞬の波のあと、空間は完全には元に戻らない。
- **出現**: 40%ロール。震源1点＋膨張リング（`gravWaves` と同レベル**非配置**: `gravWaves.length===0`）。
  周期 `GWM_PERIOD=480`f（重力波より遅い）。
- **分類**: パルス型（波面通過）＋**WeakMap 残滓**（通過後90fだけ微小バイアス力が残る）。
- **物理**:
  1. リング帯（半幅 `GWM_BAND=16`）が `GWM_R0=50` から `GWM_R1=240` まで膨張（重力波テンプレ）。
  2. 波面通過瞬間: 速度を `+GWM_KICK`（0.10rad）回転（速度保存）＋
     `gwMemories.set(ball, { remain: 90, bx: cos(θ_wave), by: sin(θ_wave) })`。
     `θ_wave` は震源→玉の方向角。
  3. `remain>0` の間、毎フレーム `ball.vx += GWM_BIAS * bx`, `ball.vy += GWM_BIAS * by`（0.004）、
     `remain--`。90fで完全消滅。
- **詰み回避**: バイアスは弱く時間限定。回転キックも小さい。吸収・閉じ込めなし。
- **ビジュアル**: 銀灰 `#9aa8c0` の細いリングドット（重力波より淡い、alpha≤0.55）。
  メモリ中の玉の後方に銀1pxの「歪み尾」3粒（`fxTrail`, 色 `#9aa8c0`）。
- **アニメーション**: 常時=リング膨張（0.35px/f）＋フェードアウト後120fで再凝縮。
  通過時=震源から銀のリング衝撃波（10f）。メモリ残滓中=尾が震源方向と逆に伸びる（空間が歪んだ暗示）。
- **Tier**: 2（波面は可視、残滓は微細だが航跡で tell）。
- **実装メモ**: `GameState.gwMemories: WeakMap<Ball, { remain: number; bx: number; by: number }>`。
  `initLevel` で `new WeakMap()`。インターフェース `GravWaveMemory { ex; ey; radius; timer; period }` または
  既存 `GravWave` を流用せず専用1要素配列 `gravWaveMemories` を推奨（描画色の差別化）。
  定数: `GWM_PERIOD=480`, `GWM_BAND=16`, `GWM_KICK=0.10`, `GWM_BIAS=0.004`, `GWM_MEM_DUR=90`。
- **検証**: 波面1回通過で回転＋90fバイアス・91f目でバイアスゼロ・速度保存（kickのみ）・
  `gravWaves` 共存なしを孤立simで確認。

### 5.58 愛因シュタイン十字 — Einstein Cross（Lv目安 94）

- **元ネタ**: 前景銀河の重力レンズで背景クエーサーが**同一天体の4像**に分裂して十字状に見える
  （Huchra's Lens 等）。4点に同じ光源が写る。
- **出現**: 45%ロール。レンズ核1点＋4像点（核から半径 `ECROSS_R=58`、角度は hubAngle + n·π/2 + jitter）。
  jitter は ±0.12rad 以内（`einCrossRng`）。
- **分類**: 連続フォース型・多点合成（原始BH群の「見える版」）。
- **物理**: 各像点 `i` に対し `R=85`, `f=ECROSS_PULL * t*t`（0.14）の引力を**ベクトル和**で加算。
  吸収なし。4点の引きが合成され、十字の「谷」で軌道が十字形に揺れる。
  合力の最大値は単一BHより弱く設計（詰み回避）。
- **詰み回避**: 弱い多点引力のみ。像点間の谷は必ず通過可能。stuck-rescue 圏内の強さ。
- **ビジュアル**: 核 `#6a5830`（暗琥珀）の3pxドット＋4像 `#c8a030`（琥珀）の2pxドット。
  核と像を細い `#e8d080` 1px線（4本）で結ぶ（レンズ系の見えない線を可視化）。
- **アニメーション**: 常時=4像が核を中心にごく遅い呼吸（k=0.004、半径±3px）。
  玉が十字近傍にいる間、最寄りの像だけ8f明滅（k=0.12、テレグラフ的 tell）。
  接触演出なし（力のみ）。
- **Tier**: 2（4像＋核が常に可視）。
- **実装メモ**: `EinsteinCross { cx; cy; hubAngle; images: {x;y}[] }` を1個生成。
  像座標は generateLevel 時に確定（実行時に動かさない）。原始BH群ループを4回に置換。
  `primordialBHs` とは同時生成してよい（見え方が正反対）。
  定数: `ECROSS_R=58`, `ECROSS_PULL=0.14`, `ECROSS_RANGE=85`。
- **検証**: 十字中心から4方向へ引力合成が非ゼロ・対称性・300f以内に領域外離脱・
  最大速度≤22を孤立simで確認。

### 5.59 量子ゼノ観測域 — Quantum Zeno Observation Sector（Lv目安 98）

- **元ネタ**: 量子ゼノ効果——観測の頻度が高いほど系の時間発展が止まる。=#46 CCC や #53 CTC とは別軸の

- **出現**: 35%ロール。楕円1個（`ZENO_RX=108`, `ZENO_RY=76`）。**#47 無とは同レベル非配置**

- **分類**: 場の修飾型・観測デューティ（時間膨張の impulsive 入退場とは異なる連続デューティ）。
- **物理**: 楕円内かつ「観測窓開放中」（`sin(frame * ZENO_DUTY_FREQ) > 0`、FREQ=0.16）のとき、
  連続フォース群の**後**（重力・他フォース適用後）に `ball.vx *= ZENO_SCALE`, `ball.vy *= ZENO_SCALE`
  （`ZENO_SCALE=0.93`）。観測窓閉鎖中は追加効果なし。
  重力は毎フレーム通常適用（完全停止にはしない）。
  `effMinSpeed` 抑制は不要（減速は弱くデューティ50%）。
- **詰み回避**: 平均減速は約7%×50% duty＝極弱。観測が「閉じた」フレームでは自由進化。
  停留・閉じ込め・吸収なし。
- **ビジュアル**: 楕円内に観測孔 `#2a9a8a`（青緑）の1pxドットを円周上に12個。
  観測開放中だけドットが明滅（k=0.22、高速＝観測中）、閉鎖中は alpha 0.15 で静止。
  楕円の長軸方向にインク `#1a4a44` の短いスポーク4本（観測装置の暗示）。
- **アニメーション**: 常時=観測孔12個が duty 位相と同期して明滅（ゼノの「観ている／していない」）。
  観測中に玉が内部にいると、玉のドット描画のみ半フレーム遅れの残像1個（表示のみ、実座標は連続）。
  白は使わない。
- **Tier**: 3（場は淡いが観測孔の明滅が tell 必須）。
- **実装メモ**: #17 時間膨張（`dilated` 入退場 impulsive）・#53 CTC（巻き戻し）と**干渉しない設計**。
  Ball 新フィールド不要。描画の残像は `ball` の表示座標オフセットでよい（量子泡のスナップと同趣旨）。
  定数: `ZENO_RX=108`, `ZENO_RY=76`, `ZENO_SCALE=0.93`, `ZENO_DUTY_FREQ=0.16`。
- **検証**: duty開放フレームのみ減速・閉鎖フレームで不変・500f平均速度比≈0.96〜0.98・
  16開始条件すべて離脱を孤立simで確認。
