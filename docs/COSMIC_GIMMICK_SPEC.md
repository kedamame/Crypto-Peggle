## 1. 共通実装レシピ

### 1.1 物理分類と対応テンプレ

| 分類 | 挙動 | コピー元 | サブステップ | effMinSpeed |
|---|---|---|---|---|
| 連続フォース型 | 範囲内で毎フレーム `vx/vy` に加算 | レンズ or パルサー | 不要 | 不要（加速のみなら） |
| パルス型 | 周期タイマー→短時間だけ強い力 | 重力波（波面）+ CME（予告演出） | 不要 | 不要 |
| 接触衝突型 | 重なった瞬間に反射/消滅/シフト | 彗星（円）or バンパー/ワームホール（OBB） | **必須** | 反射後に**必須** |
| 場の修飾型 | 範囲内で重力・速度スケールを変える | 真空バブル + freeze/mud の minSpeed 抑制 | 不要 | **抑制側の配慮が必須**（§1.4） |

### 1.2 決定論ルール（§7.6）

- 出現判定・座標・向きなど**レベル生成時**の乱数は、専用ストリーム
  `const xxxRng = makeRng((rng() * 0x100000000) >>> 0);` を **`generateLevel` 内の既存の全乱数消費の後ろ**
  （現在は `vacRng` ブロックの直後）に追加して使う。既存レベルの配置を1ビットも変えないため。
- **実行時**の毎フレーム挙動（パルスの向き再抽選・ドリフト等）は `Math.random()` でよい。

### 1.3 禁止事項

- `computeTrajectory` への反映は**いかなる場合も禁止**（§7.5。狙い線に映らない＝フェアな難しさ）。
- 背景クリーム地 `#ede9df` を塗り替えない。宇宙感はハザード自身の彩度ドットで出す。
- クリア条件（orange 全消し／ボス撃破）に干渉しない。ペグを消す・増やすギミックは作らない。
- 描画ブロックの末尾で必ず `ctx.globalAlpha = 1` に戻す。

### 1.4 詰み回避の設計指針（§4-4）

- 玉を減速・停留させる案は、**freeze/mud と同じ per-ball タイマー方式**で `dynMinSpeed` を抑制しつつ、
  効果に時間上限を付ける（stuck-rescue 220f が最終保険だが、頼り切らない）。
- 玉を閉じ込めうる案（上向き力・停留場）は、**周期的な解放**（ポップ/フェーズ消滅/移動）を必ず設計に含める
  （真空バブルの「rMax でポップ」が実例）。
- 力は距離減衰 `t = 1 - dist/range; f = BASE * t * t` に統一し、速度は必要に応じ `BALL_SPEED * 2` でクランプ。

### 1.5 配色の原則

既存ハザード色（重複を避ける）: BH=血赤 / ワームホール・レンズ・霧=紫 / 青彗星=空色 / 赤彗星=赤 /
CME=橙 / パルサー=シアン白 / 重力波=銀灰 / 真空バブル=緑。
各案のビジュアル欄に指定色を記載済み。ハザードは「クリーム地に紛れ込んだ自己発光の異物」に見えること。

### 1.6 共通アニメーション言語（各案の「アニメーション」欄はこの語彙で指示される）

動きの発明は禁止。すべての動きは、実コード（`src/components/CryptoPeggleGame.tsx`）に既にある
次の10イディオムの組み合わせで作ること。**動きは全てドットの明滅・移動・回転で表現する**
（形状変形やスケーリングは「点描の再配置」として行う）。

| イディオム | 数式/手法 | 実例（コード内） |
|---|---|---|
| **パルス明滅** | `a = base + Math.abs(Math.sin(frame*k))*amp`。k=0.004〜0.06=鈍い/不気味、0.1〜0.15=通常、0.2〜0.33=危険/高速 | bombペグ k=0.14、パルサー k=0.22、シールド k=0.11 |
| **回転ドットリング** | `angle = (i/n)*2π ± frame*k`。k=0.008〜0.035 | レンズ、ボス内輪、パルサーのハロー |
| **リング衝撃波** | 半径 `r0 + t*Δr`・alpha `(1-t)*a0` を10〜36fで展開 | ボス rearmFlash（18f）、彗星 hitFlash（26f） |
| **点滅予告（テレグラフ）** | 発動30〜45f前から明滅、強度は `wt = 1 - timer/WARN` でランプ | 彗星の端シェブロン、CMEの警告バー（40f） |
| **ドット流（フロー）** | 位置を `(base + frame*spd) % length` でスクロール | 霧の雲（spd 0.18〜0.56）、彗星の尾 |
| **ヒットフラッシュ** | `hitFlash` カウントダウン中は白/明色に差し替え | ボス（10f）、バンパー（20f） |
| **バースト** | `spawnBurst(g, x, y, vx, vy, color)` を1発 | 全ハザード共通の接触演出 |
| **微ジッター** | 事前計算 cosP/sinP 方式（`Dot` interface / `drawDots`） | 全ドット雲。**per-frame の生 trig 大量呼びは禁止** |
| **フェード生滅** | alpha を約20fでランプ（`WORMHOLE_FADE = 20` が基準。10〜36fの範囲内） | ワームホールの出現/消失 |
| **呼吸** | 半径やサイズを `1 + sin(frame*k)*0.03〜0.06` で揺らす | 泥ペグの wobble（k=0.06） |

**テンポの世界観ルール**:
- 不気味なもの・古いもの・巨大なものほど**遅く**（k ≤ 0.06）、危険なもの・小さいものほど**速く**（k ≥ 0.2）。
- 深度ゾーンが深いほど動きは「静かで異様」に（各ゾーンバナーのトーン指針に従う）。
- 予告→発動を持つものは必ずテレグラフを入れる（プレビュー無反映の代償として、動きで読ませる）。

**禁止事項**: クリーム地の塗り替え / radial-gradient・box-shadow 的表現の多用 /
`globalCompositeOperation` の使用 /
1フレームあたり数百回超の生 `Math.sin/cos` 呼び（事前計算かメモ化 `circleTrig` を使う）/
描画ブロック末尾の `ctx.globalAlpha = 1` 戻し忘れ。

## 2. ギミックカタログ（47案・浅→深で exotic 度が増す）

### 2.0 深度マップ — レベルは「宇宙の深部への旅」

レベル進行を**観測可能な宇宙を内から外へ、そして時間を遡って始まりの向こうへ**降りていく旅として設計する。
深いゾーンほど現象は未知・異様・強力になり、最後は物理法則そのものが崩れる。
ボス階層（lv30/40/50/60/70/80/90/100）は各深度の「門番」として機能する（ボス自体の変更は不要）。

| レベル帯 | 深度 | 内容 |

| 7〜20 | 太陽系〜恒星間空間 | 実装済み: BH・ワームホール・彗星・レンズ・霧・CME |
| 22〜29 | 恒星の残骸・時空の異常 | 実装済み: パルサー・重力波・真空崩壊バブル |
| 23, 31〜39 | 銀河系の深部 | カタログ #1〜#10 |

| 61〜65 | **ゾーンB: 宇宙網・大規模構造** | カタログ #29〜#33 |
| 71〜77 | **ゾーンC: 初期宇宙・観測の果て** | カタログ #34〜#39 |

### 2.1 ホワイトホール — White Hole（Lv目安 23）
- **元ネタ**: ブラックホールの時間反転解。何も入れず、すべてを吐き出すだけの仮説上の天体。
- **出現**: 50%ロール。スケーリング: 斥力 `0.55 + min(0.55, (lv-23)*0.03)`。
- **分類**: 連続フォース型（**BH引力ブロックのコピー・符号反転・吸収判定を削除**）。
- **物理**: 範囲 `R=140`。`t=1-dist/R; f=WH_PUSH*t*t; ball.v += (d̂_中心→玉) * f`（外向き）。
- **詰み回避**: 斥力のみ＝玉を留める力が存在しない。
- **ビジュアル**: BHの渦の白黒反転。純白〜青白（`#ffffff`/`#e8f0ff`）の**逆回転**する噴出渦ドット＋
  白コア（`drawSolidCircle`）。プレイヤーが「BHの逆だ」と直感できる形にする。
- **アニメーション**: 常時=噴出渦を回転ドットリング（k=0.02、**BHと逆回転**）＋中心→外への
  ドット流（spd 0.8、外縁でフェード）。白コアのみパルス明滅（k=0.08）。
  接触=玉が押された瞬間、玉と中心を結ぶ線上に白1pxスパーク2個（3f）。生滅=なし（常設）。
- **実装メモ**: 最も簡単な1案。既知（BH）の反転なので「未知」導入の入口に最適。

### 2.2 マグネター — Magnetar（Lv目安 31）
- **元ネタ**: 宇宙最強の磁場を持つ中性子星。星震で巨大フレアを放つ。
- **出現**: 50%ロール。パルス周期 `max(180, 300-(lv-31)*8)` フレーム。
- **分類**: パルス型（重力波の周期タイマー＋CMEの予告演出を合成）。
- **物理**: 帯電40f（予告）→ 放出6f: 範囲 `R=170` 内の全玉に
  `f=1.6*t*t` の外向きインパルス/フレーム。放出後は無害。
- **詰み回避**: 瞬発の斥力のみ。
- **ビジュアル**: 鉄灰の星体（小さい `drawSolidCircle`）＋黄白（`#ffe66a`/`#fff8d0`）の磁力線アーチが
  帯電中に明滅→放出時に全方位スパーク（`spawnBurst` 黄白）。
- **アニメーション**: 常時=星体を鈍いパルス明滅（k=0.05）＋磁力線アーチの回転ドットリング（k=0.01）。
  予兆=放出40f前から磁力線が速いパルス（k=0.25）へ移行し白熱（テレグラフ）。
  発動=リング衝撃波（6f、R=170まで、黄白）＋ `spawnBurst` 黄白。
  接触=力を受けた玉ごとに1px白スパーク3個。生滅=フェード20f。
- **実装メモ**: 予告→炸裂のリズムは CME の `WARN` パターンを流用。

### 2.3 ローグプラネット — Rogue Planet（Lv目安 32）
- **元ネタ**: 恒星を持たず銀河を漂う自由浮遊惑星。暗黒の中を静かに横切る。
- **出現**: 45%ロール。移動速度 `0.35 + (lv-32)*0.01`（ゆっくり）。
- **分類**: **移動する**連続フォース型＋接触衝突型（彗星の移動＋バウンス、BHの引力を合成）。
- **物理**: 半径 `r=22` の実体（法線反射・彗星の式を流用、**effMinSpeed クランプ必須**）＋
  周囲 `R=130` の引力 `f=0.35*t*t`。画面を横断し、端で反対側から再進入（または折り返し）。
- **詰み回避**: 惑星自体が移動し続けるため停留点が存在しない。吸収なし。
- **ビジュアル**: 濃藍鼠（`#20283a`）の点描惑星＋淡灰のリング（傾いた楕円ドット列）。
  発光しない「暗い異物」として描く（唯一の非発光ハザード＝はぐれ感）。
- **アニメーション**: 常時=移動そのものが主アニメ。自転は `drawDots` の rot 引数でごく遅く（k=0.004）、
  リングは呼吸（k=0.02、振幅0.04）。**発光の明滅は一切入れない**（暗い異物の演出）。
  接触（バウンス）= `spawnBurst` 灰藍＋ヒットフラッシュ8f。生滅=画面外へ出て反対側から再進入（フェード不要）。
- **実装メモ**: 引力＋実体の合成でスリングショット（加速旋回）が自然に発生する。

### 2.4 クエーサージェット — Quasar Jet（Lv目安 33）
- **元ネタ**: 超大質量ブラックホールが噴き上げる光速級のプラズマ柱。
- **出現**: 45%ロール。加速 `0.30 + (lv-33)*0.015`。
- **分類**: 連続フォース型（パルサーのビーム判定を**固定角・片方向**にした変形）。
- **物理**: 生成時に柱の位置 x・向き（上噴き/下噴き）・半幅 `HALF=16` を決定。柱内の玉に
  軸方向の加速を毎フレーム加算、`BALL_SPEED*2` でクランプ（風と同じ作法）。
- **詰み回避**: 一方向への加速のみ。上噴きの場合も柱の外に出れば通常重力（左右移動は自由）。
- **ビジュアル**: 菫色（`#8a5adc`）の柱状ドット流（流れ方向にドットがスクロール）＋
  柱の根元に小さな輝点コア。紫系だがレンズより明るい菫で差別化。
- **アニメーション**: 常時=柱内を軸方向のドット流（spd 2.5、根元が濃く先端でフェード）＋
  根元コアのパルス明滅（k=0.18、危険信号）。
  接触=玉が柱に入った瞬間、玉の後方に短い白ストリーク（3f）。生滅=なし（常設）。
- **実装メモ**: パルサーの `along/perp` 内積・外積判定をそのまま使い、`sgn` を固定する。

### 2.5 蒸発するマイクロブラックホール — Evaporating Micro BH（Lv目安 34）
- **元ネタ**: ホーキング放射。小さいブラックホールほど速く蒸発し、最後は爆発的に消える。
- **出現**: 45%ロール。寿命 `~700f`（レベルで短縮）。
- **分類**: 連続フォース型＋パルス型（BH引力＋真空バブルのライフサイクル）。
- **物理**: 引力 `f=0.5*t*t`（範囲 `R = 40 + 寿命残比*80`＝**縮みながら弱まる**）。吸収なし。
  寿命0で蒸発: 12fの斥力バースト `f=2.0*t*t` → 90f休止 → 別のシード済み候補地に再出現。
- **詰み回避**: 吸収なし＋周期的に消滅。引力最大でも stuck-rescue 圏内の強さ。
- **ビジュアル**: BH族とわかる血赤〜栗色の小渦（本家の1/3スケール）＋縮小に伴い白い
  ホーキング放射スパーク（1pxドット）が増える。蒸発時は白閃光バースト。
- **アニメーション**: 常時=血赤渦の回転ドットリング（k=0.03、本家より速い=小さく忙しない）。
  縮小に応じて白ホーキングスパーク（1px）の頻度を上げる（寿命残90%で30fに1個→残10%で6fに1個）。
  予兆=蒸発10f前に渦全体が白へ遷移。発動（蒸発）=リング衝撃波（12f、白）＋ `spawnBurst` 白×2連。
  生滅=再出現はフェード生滅20f＋収縮リング（衝撃波の逆再生風）。
- **実装メモ**: 再出現候補地（2〜3点）は生成時に専用rngで決めておき、実行時に順繰り使用。

### 2.6 ダークマター・ハロー — Dark Matter Halo（Lv目安 48）
- **元ネタ**: 宇宙の質量の約27%を占める正体不明の見えない質量。重力でしか観測できない。
- **出現**: 45%ロール。引力 `0.30 + (lv-35)*0.015`。
- **分類**: 連続フォース型（磁石ペグの引力式を大型化）。
- **物理**: 範囲 `R=160`、`f=DM_PULL*t*t` の引力。吸収なし。**ほぼ描画しない**のが本体。
- **詰み回避**: 弱い引力のみ（BHの半分以下）。中心に実体がないので玉は素通りして振り子軌道になる。
- **ビジュアル**: 常時は**何も描かない**。90f周期で1回だけ、極淡い藍（`#6a76a8`、alpha 0.05-0.10）の
  リングシマーを1秒弱表示（「そこに何かある」最小限のフェアネス）。玉が範囲内にいる間は
  中心方向に玉の軌跡スパーク（`spawnBurst` を間引き）で歪みを暗示。
- **アニメーション**: 常時=無描画（動きの不在が本体）。90f周期のシマー=リングをフェードイン10f→
  フェードアウト30f（alpha≤0.10）。接触=範囲内の玉の軌跡側に1px藍スパークを3fごとに1個
  （見えない歪みの可視化）。生滅=なし。
- **実装メモ**: 「見えない引力」はプレビュー無反映の思想（§4-2）の極致。効果は控えめに調整する。

### 2.7 エルゴ球 — Ergosphere（Lv目安 36）
- **元ネタ**: 回転ブラックホール（カー解）の周囲で時空自体が引きずられ、静止が不可能になる領域。
- **出現**: 45%ロール。引きずり `0.5 + (lv-36)*0.02`。
- **分類**: 連続フォース型（レンズの接線力を**リング帯ゲート**にした変形）。

### 2.20 銀河潮汐ストリーム — Tidal Stream（Lv目安 51）

### 2.21 アインシュタイン鏡像リング — Einstein Mirror Ring（Lv目安 52）

### 2.22 裸の特異点 — Naked Singularity（Lv目安 53）
- **元ネタ**: 事象の地平線を持たない特異点。物理法則が破綻した点が剥き出しで存在する（宇宙検閲官仮説への反逆）。

- **物理**: 範囲 `R=110`。力の向きが**角度と時間の関数で乱流的に切り替わる**:
  `sign = sin(3θ + frame*0.02)` の符号で接線方向を反転しつつ、`f = 0.9*t*t*t`（3乗＝中心ほど激烈）。

- **詰み回避**: 常時外向き成分を混ぜてあるため長期滞在は不可能。吸収なし。
- **ビジュアル**: 黒コア（`drawSolidCircle`）の周囲で血赤（`#c01030`）と純白のドットが

  時折1フレームだけ全ドットが静止する（法則の破綻）。
- **アニメーション**: 常時=血赤と白の回転ドットリングだが、**回転速度自体が揺れる**
  （`k(frame) = 0.05 * sin(frame*0.013)` ＝回転が止まり、逆転する）。約90fに1回、全ドットが
  1f完全静止する（法則の破綻の瞬間）。接触=範囲内の玉の軌跡を1px血赤で3f残す（乱流の可視化）。
  生滅=なし（常設）。
- **実装メモ**: 乱流の `sin(3θ + frame*k)` は決定的な式なので再現性がありデバッグ可能。
  「予測不能に見えるが実装は単純」が狙い。

### 2.45 ビッグリップ前兆 — Big Rip Precursor（Lv目安 93）
- **元ネタ**: ダークエネルギーが強まり続ける（ファントム）なら、宇宙は銀河も原子も引き裂いて終わる。

- **詰み回避**: 斥力のみ。中心付近はほぼ無力。
- **ビジュアル**: イベント中、背景インク点の間隔が中心から比例して広がり、ゆっくり戻る

- **実装メモ**: #19 ダークエネルギー膨張域（局所・定常）との差別化＝全域・パルス・漸増。

### 2.46 共形サイクリック境界 — Conformal Cyclic Boundary（Lv目安 95）
- **元ネタ**: ペンローズCCC——宇宙の無限の未来と次の宇宙のビッグバンは、共形変換でつながった同じ面である。
  終わりは始まり。
- **出現**: 40%ロール。
- **分類**: 特殊（境界の再定義。**唯一、玉の経済に触れる案**——採否判断は下の注記を参照）。
- **物理**: 画面最下端に高さ20pxの境界帯（バケットのさらに下）。バケットに入らず落ちた玉が帯に
  達したとき、**その玉が未再誕なら**上端（発射台の左右ランダム）から速度の大きさを保存して
  再誕する（per-ball フラグで1玉1回）。2回目は通常どおり退場。
- **詰み回避**: 詰みとは逆方向（救済）。クリア条件には無関係。
- **ビジュアル**: 下端に極淡の虹色地平線（1pxの7色ドット列、alpha 0.2）。再誕時は上端に
  白い産声バースト＋新しい宇宙の最初の玉として一瞬金色に光る。
- **アニメーション**: 常時=虹色地平線ドット列の超遅い横送り（ドット流 spd 0.1、7色が順送り）。
  発動（再誕）=下端の接触点から白ドット1粒が上端まで縦に駆け上がる（6f）→上端で
  `spawnBurst` 白＋金の産声→再誕した玉が10f金の残光を纏う（バケットボールのブルームを短縮流用）。
  生滅=なし（常設）。
- **注記**: 玉1個あたり実質約1.5回のチャンスになるため、**深層の高難度を相殺するご褒美ギミック**
  として設計している。難度を下げたくない場合は不採用に。
- **実装メモ**: 玉の除去判定（`ball.y > H+40`）の直前に帯判定を挟む。

### 2.47 無 — The Nothing（Lv目安 99）
- **元ネタ**: 宇宙の外には何があるのか。空間も時間も法則もない「無」。この問いに物理学はまだ一文字も書けていない。
- **出現**: 35%ロール（最深部の到達点）。
- **分類**: 場の修飾型・**全ての力の不在**。
- **物理**: 円領域（R=110）。内部の玉には**重力を含む一切の力を適用しない**——完全な直線等速運動。
  minSpeed も stuck タイマーも領域内は凍結（直線なので詰まない）。壁・ペグ衝突だけは生かすが、
  生成時に領域内へペグ・他ハザードを配置しない。
- **詰み回避**: 直線運動は必ず領域を貫通して出る（力がないので留まれない）。
- **ビジュアル**: **何も描かない**。背景のインク点・微グレインさえ領域内では描画をスキップする。
  完全な空白の円。境界線すらない——インク点が円形に欠けていることだけが、そこに「無」がある証拠。
  玉が通過する間、玉の点描だけが空白に浮かぶ。
- **アニメーション**: **一切動かない**。内部は何も描かず、境界線もなく、bgDots が円形に欠けるだけ。
  接触・生滅の演出もゼロ。47案で唯一「アニメーションを持たないこと」自体が指示。
  実装者は装飾を足したくなっても**足さないこと**（何かを足した瞬間、それは「無」ではなくなる）。
- **実装メモ**: 力適用セクションの冒頭で `inNothing` を判定し、重力〜全ハザード力をガードする。
  #12 宇宙ボイド（低重力＋ドラッグ＝「薄い」）との差別化＝こちらは物理の**完全な不在**。
  カタログ全体の終着点として、最も静かで最も異様な一枚に仕上げること。
